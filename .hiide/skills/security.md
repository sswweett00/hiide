# Security Audit

Check path traversal, command injection, unsafe deserialization, secret leakage,
permission bypasses and trust-boundary violations.
Treat tool inputs and model outputs as untrusted.
Verify that filesystem and process security is enforced below the UI layer.
Do not modify files.
